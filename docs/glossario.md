# Glossário

| Termo | Definição |
|---|---|
| IA generativa | Tecnologia capaz de produzir novos conteúdos, como textos, imagens, código e áudio, a partir de instruções. |
| Prompt | Instrução fornecida a um sistema de IA para orientar sua resposta. |
| LLM | Modelo de linguagem de grande porte treinado para processar e gerar linguagem. |
| Alucinação | Resposta incorreta ou inventada apresentada pela IA com aparência de verdade. |
| Grounding | Fundamentação da resposta em fontes ou dados identificáveis. |
| RAG | Técnica que recupera informações externas para apoiar a geração de uma resposta. |
| Revisão humana | Validação feita por uma pessoa antes da aplicação ou publicação de uma saída da IA. |
| SaaS | Software disponibilizado como serviço, normalmente pela internet. |
| MVP | Versão mínima de um produto usada para testar hipóteses com usuários reais. |
| Beta controlado | Teste limitado a um grupo pequeno de usuários antes de uma liberação mais ampla. |
| Perfil da Empresa no Google | Recurso usado por empresas para gerenciar como aparecem na Pesquisa e no Maps. |
| SEO local | Práticas voltadas à visibilidade de negócios em buscas associadas a uma região. |
| Relevância | Correspondência entre a empresa e a intenção da pesquisa. |
| Distância | Proximidade entre o estabelecimento e a localização considerada na busca. |
| Destaque | Grau de notoriedade de uma empresa, influenciado por sinais como links e avaliações. |
| Health Score | Pontuação proposta pelo LocalLift AI para resumir a saúde do perfil com critérios explicáveis. |
| Keyword stuffing | Uso artificial e excessivo de palavras-chave para tentar manipular resultados. |
| Conteúdo útil | Conteúdo criado para atender às necessidades do usuário e oferecer valor real. |
| Viés | Tendência que pode produzir resultados injustos ou sistematicamente distorcidos. |
| Governança de IA | Regras, responsabilidades e controles para desenvolver e usar IA de forma responsável. |
| Transparência | Comunicação clara sobre dados, critérios, limitações e participação da IA. |
| Privacidade | Proteção e tratamento adequado de dados pessoais ou empresariais. |
| API | Interface que permite a comunicação entre sistemas de software. |
| Teste de ponta a ponta | Verificação de um fluxo completo do início ao fim. |
| Plano de ação priorizado | Conjunto de tarefas ordenadas por critérios como impacto, urgência e esforço. |
